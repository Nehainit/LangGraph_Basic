Questions

Will my characters look the same in every shot?

Yes. Softframe draws a character sheet for each character first and uses it as the reference for every frame. That’s how the rabbit stays the same rabbit for the whole race.

Which languages can it narrate in?

Hindi and English today. Subtitles follow the narration. If you need another language, pick “Another language” on the waitlist so we know.

Can I fix a frame I don’t like?

Yes. You review the full storyboard before anything is animated and can redraw individual frames. Once you approve it, the film is made from exactly those frames.

How long can a film be?

Up to 30 seconds per film today, which fits YouTube Shorts and Instagram Reels. Longer films are on the roadmap.
